# Sunny Widgets

Transparent Spotify home-screen widgets plus an audio visualizer overlay for Android.

- **Sunny Player** (4x2): album art, title, artist, progress bar, prev/play/next. Accent colour follows the album art. Optional "ghost" outline text with an art-coloured gradient.
- **Sunny Mini** (4x1): one-line strip with play/next.
- **Visualizer**: spectrum bars floating along the bottom of the screen while music plays. Draws over the launcher.

## Install
Grab `SunnyWidgets.apk` from the latest release, install, then open the app and grant:
1. Notification access (how Android lets an app read what's playing)
2. Draw over other apps (for the visualizer)
3. Microphone (Android's visualizer API needs it to read the audio output; nothing is recorded)

Then long-press the home screen → Widgets → Sunny Widgets.
